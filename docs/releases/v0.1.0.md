# CodexBoard 0.1.0

Every task has a state. Every change has a gate.

CodexBoard 0.1.0 is the first GitHub Pre-release of a macOS control plane for
Codex work. It turns project tasks into a visible path from read-only planning
through approval, isolated execution, evidence, and review.

## Highlights

- Multi-project task board with manual and Auto-run workflows.
- Frozen model, effort, and Fast configuration for every task.
- Local Skills, read-only Apps, MCP connections, and explicit human approvals.
- Git worktree isolation, dependency handoffs, safe cleanup, and execution limits.
- Delivery artifacts, test evidence, unified diffs, and review history.
- Approval notifications that return to the exact waiting task.
- English and Simplified Chinese UI plus bilingual project landing pages.
- Apache License 2.0 source licensing with third-party attribution and separate
  CodexBoard trademark guidelines.

## Install this local preview

1. Download `CodexBoard-v0.1.0-macOS.zip` from the release assets.
2. Verify its SHA-256 value against `CodexBoard-v0.1.0-SHA256SUMS.txt`.
3. Extract the archive and move `CodexBoard.app` to `/Applications` if desired.
4. Because this preview is ad-hoc signed and not notarized, macOS may block a normal first launch. Build from source if you do not explicitly trust the preview artifact.

## Requirements

- macOS 14 or later on Apple silicon.
- A local Codex CLI or trusted Codex application, already signed in.

## Trust boundary

This preview is **not** Developer ID signed or Apple notarized. It is intended for local evaluation by people who can inspect or build the source. A future public release must use a stable production bundle identifier, hardened runtime, Developer ID signing, notarization, stapling, and Gatekeeper verification.
